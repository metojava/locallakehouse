Big Data Transformation with Iceberg, Spark & Delta

A hands-on guide using the Open Lakehouse Workbench

This book teaches you how to load, transform, and manage large datasets using Apache Spark, Delta Lake, and Apache Iceberg — all from your own computer. The Open Lakehouse Workbench gives you a SQL editor, a PySpark runner, and a local catalog so you can experiment without cloud accounts or clusters.
